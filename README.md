## Descripción

Agencia Palenque es un proyecto web académico desarrollado para
promocionar el cantón Palenque, ubicado en la provincia de Los Ríos,
Ecuador.

El sitio presenta información turística relacionada con sus paisajes,
naturaleza, historia, tradiciones montubias y gastronomía.

La agencia turística es ficticia y fue creada como parte del examen
práctico de Diseño de Sitios Web.

---

## Atractivos turísticos

El sitio presenta información sobre:

- Balneario de agua dulce La Reveza.
- Reserva de Jauneche.
- Humedal Las Garzas.
- Iglesia San Nicolás.
- Casa de Nicolás Infante.
- Tradiciones montubias.

---

## Gastronomía

Dentro del contenido se presentan referencias a la gastronomía
tradicional de Palenque, incluyendo:

- Bollo de pescado.
- Chanfaina.
- Cazuela de pescado.
